# timewall

Session-bound wallpaper selection with a black fallback, plus a fixed dark Caelestia
theme applied at session start. The theme no longer changes with local time; manual
Caelestia changes remain available until the next session start.

Import `default.nix` from Home Manager. Tests and supporting fixtures live in
`tests/`; run commands from the repository root using the [test index](../../tests/README.md).
